# Alder

**Локальная станция · Beta v0.1**

Файлы, заметки и переписка на одной машине. Перетащил — и они связаны.

Изменён на основе [Free-FS](https://github.com/dromara/free-fs). [Apache License 2.0](LICENSE). Источник — в [NOTICE](NOTICE).

Alder — **локальная рабочая станция**: одна машина (или один Docker Compose) поднимает весь сайт для офиса или дома. Это не публичный диск. Сейчас **Beta v0.1**, интерфейс и API ещё изменятся.

Одна идея: **пространство, заметки и переписка — три входа к одному и тому же**. Не скачивать и не заливать заново.

## Пространство

У каждого пространства свои файлы, участники, роли и хранилища. По умолчанию — локальный диск. Объектное хранилище (MinIO / OSS / COS и другой S3) привязано к пространству; смена пространства его прячет.

Сетка или список, можно два окна. Уже лежащий файл проходит сразу. Локальный диск продолжает через Tus. Картинки, Office, звук и видео открываются на странице.

## Заметки

Слева заметки, справа общая колонка `fileshare`. Между ними можно таскать. Файл пространства в заметке — **карточка-ссылка**, не копия; карточка открывает место файла. Файл с компьютера сначала попадает в колонку.

Совместная работа — Yjs, онлайн-изменения — SSE. Если файл потом удалить, карточка помечается недействительной.

## Переписка

Окно висит на любой странице. Библиотеку можно не закрывать: файл пространства уходит в беседу (тот же файл), файл из беседы **копируется** в папку. На заметку: сначала копия в `fileshare`, затем карточка-ссылка.

Личные беседы, группы, цитата, отзыв, прочитано. Текст шифруется на устройстве.

Как таскать:

| Откуда | Куда | Что происходит |
| --- | --- | --- |
| Файл пространства | Заметка | Карточка-ссылка, без копии |
| Файл пространства | Разговор | Этот уже существующий файл уходит в беседу |
| Файл из разговора | Пространство | Копируется в папку под указателем |
| Файл из разговора | Заметка | Сначала в колонку, затем карточка |
| Файл с компьютера | Заметка | Загружается в колонку и попадает в заметку |

## Развёртывание (локальная станция)

Нужны [Docker](https://docs.docker.com/get-docker/) и Docker Compose. Первая сборка тянет образы JDK / Node и занимает несколько минут.

```bash
git clone <этот-репозиторий> alder && cd alder
docker compose up -d --build
```

Откройте **http://localhost**. API также на `http://localhost:8080` (документация `/swagger-ui.html`).

Данные в двух томах: `alder-pg` (PostgreSQL) и `alder-files` (локальные загрузки). Остановка контейнеров их не стирает.

```bash
docker compose logs -f gateway
docker compose down          # стоп, тома остаются
docker compose down -v       # стоп и очистка базы и файлов
```

Учётная запись Compose по умолчанию — `alder` / `alder`, только для закрытой сети. Перед выходом наружу смените пароль и JWT, заполните почту и CORS в настройках сайта. Встречи через интернет требуют свой TURN.

Без Docker: JDK 21, Maven, PostgreSQL, Redis, Node.js. Скопируйте `application.example.yml` и `application-dev.example.yml` без `.example`. Запускайте только `Gateway` (без `-am`). Фронт `npm run dev` слушает `http://localhost:5180`.
